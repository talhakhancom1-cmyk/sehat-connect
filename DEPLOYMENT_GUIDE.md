# EcoHealth — Deployment Guide

Complete guide to deploy EcoHealth on a fresh VPS without errors.

## Prerequisites

### What you need before starting:
1. **A VPS** running Ubuntu 22.04 / 24.04 / 26.04 (any cloud provider)
2. **A domain name** pointed to your VPS IP (A record in DNS)
3. **Root access** to the VPS (SSH)
4. **GitHub deploy key** (if repo is private) — see below

### Minimum VPS specs:
- **RAM:** 2GB (4GB recommended for production)
- **Disk:** 20GB minimum
- **CPU:** 1 core minimum

---

## Step 1: Point Your Domain

Before deploying, make sure your domain's DNS is configured:

```
Type: A
Name: @ (or your subdomain)
Value: <your-vps-ip-address>
TTL: 3600
```

Verify it's working:
```bash
dig +short yourdomain.com
# Should return your VPS IP
```

Wait 5-30 minutes for DNS to propagate.

---

## Step 2: Connect to Your VPS

```bash
ssh root@your-vps-ip
```

If you get a host key warning, accept it.

---

## Step 3: Set Up GitHub Deploy Key (if repo is private)

On your VPS, generate an SSH key:
```bash
ssh-keygen -t ed25519 -C "vps-deploy" -f ~/.ssh/id_ed25519_deploy -N ""
cat ~/.ssh/id_ed25519_deploy.pub
```

Copy the output, then:
1. Go to your GitHub repo → **Settings** → **Deploy keys**
2. Click **Add deploy key**
3. Title: `VPS Deploy`
4. Paste the key
5. Check **Allow write access** (optional)
6. Click **Add key**

Configure SSH to use this key for GitHub:
```bash
cat > ~/.ssh/config <<'EOF'
Host github.com
  HostName github.com
  User git
  IdentityFile /root/.ssh/id_ed25519_deploy
  StrictHostKeyChecking no
EOF
chmod 600 ~/.ssh/config
```

Test it:
```bash
ssh -T git@github.com
# Should say: "Hi username! You've successfully authenticated..."
```

## Step 4: Run the Deployment Script

### Option A: Interactive (prompts for domain)
```bash
apt-get update -qq && apt-get install -y -qq git
git clone git@github.com:talhakhancom1-cmyk/ecohealth.git /tmp/ecohealth-deploy
cd /tmp/ecohealth-deploy
sudo bash deploy.sh
```

### Option B: Non-interactive (specify domain)
```bash
git clone git@github.com:talhakhancom1-cmyk/ecohealth.git /tmp/ecohealth-deploy
cd /tmp/ecohealth-deploy
sudo DOMAIN=yourdomain.com ADMIN_EMAIL=admin@yourdomain.com bash deploy.sh
```

### What the script does (10 steps):
1. **Installs system packages** — Nginx, PostgreSQL, Redis, Certbot, build tools
2. **Installs Node.js 22** — via NodeSource (not the old Ubuntu default)
3. **Sets up PostgreSQL** — creates database `ecohealth` and user with strong password
4. **Sets up MinIO** — installs S3-compatible storage, creates bucket, sets up systemd service
5. **Clones the repository** — via SSH (or HTTPS fallback)
6. **Configures backend .env** — generates all secrets, writes config file
7. **Installs dependencies** — backend (`npm install --production`) + frontend (`npm install`)
8. **Builds frontend** — `vite build` with correct API URL
9. **Configures Nginx + SSL** — generates site config, obtains Let's Encrypt cert
10. **Starts backend with PM2** — and saves process list for auto-restart on reboot

### Expected output at the end:
```
==========================================
  Deployment Complete!
==========================================

  Frontend:    https://yourdomain.com
  API:         https://yourdomain.com/api
  Health:      https://yourdomain.com/health

  Admin login:
    Email:     admin@yourdomain.com
    Password:  <auto-generated>

  IMPORTANT — Save these credentials:
  Backend .env: /opt/ecohealth/backend/.env
  DB password:  <auto-generated>
  MinIO keys:   <auto-generated> / <auto-generated>
```

**SAVE THESE CREDENTIALS IMMEDIATELY.** They are only shown once.

## Step 5: Verify Deployment

Open your browser and check:

1. **Frontend loads:** `https://yourdomain.com` — should show login page
2. **Health check:** `https://yourdomain.com/health` — should return `{"status":"ok"}`
3. **Admin login:** Use the credentials from the script output
4. **Admin panel:** Navigate to Dashboard → should show stats

If any of these fail, see [Troubleshooting](#troubleshooting) below.

## Step 6: Post-Deployment Configuration

### Configure Email/SMTP
1. Log in as admin
2. Go to **Email / SMTP** in the sidebar
3. Click a provider preset (Gmail, SendGrid, etc.) or enter custom SMTP
4. Enter SMTP credentials
5. Click **Save Settings**
6. Click **Send Test** to verify

### Create API Keys
1. Go to **API Keys** in the sidebar
2. Click **Create API Key**
3. Add allowed domains
4. Copy the key (shown once)

### Configure Firewall (recommended)
```bash
ufw allow 22/tcp    # SSH
ufw allow 80/tcp    # HTTP
ufw allow 443/tcp   # HTTPS
ufw enable
```

## Updating an Existing Deployment

To pull the latest code and rebuild:

```bash
cd /opt/ecohealth
git fetch origin
git reset --hard origin/main

# Install any new backend dependencies
cd backend && npm install --production

# Rebuild frontend
cd /opt/ecohealth && npm run build

# Restart backend (if backend code changed)
pm2 restart ecohealth-backend

# Reload Nginx (if nginx.conf changed)
cp backend/nginx.conf /etc/nginx/sites-available/ecohealth
nginx -t && systemctl reload nginx
```

## Troubleshooting

### Frontend shows "Something went wrong"
```bash
# Check browser console for errors
# Most common: API returns paginated response but frontend expects array
# Fix: ensure the API client has toArray() helper (already in latest code)

# Check if backend is running
pm2 status
pm2 logs ecohealth-backend --lines 20

# Check if Nginx is proxying correctly
curl http://localhost:3000/health
curl https://yourdomain.com/health
```

### SSL certificate fails
```bash
# Check if domain points to this server
dig +short yourdomain.com

# Run certbot manually
certbot --nginx -d yourdomain.com --agree-tos --redirect

# If port 80 is blocked by firewall
ufw allow 80/tcp
```

### Database connection error
```bash
# Check PostgreSQL is running
systemctl status postgresql

# Check .env has correct DB credentials
cat /opt/ecohealth/backend/.env | grep DB_

# Test connection
sudo -u postgres psql -d ecohealth -c "SELECT 1;"
```

### MinIO not working
```bash
systemctl status minio
# Check logs
journalctl -u minio --no-pager -n 20

# Verify bucket exists
mc alias set local http://localhost:9000 <access_key> <secret_key>
mc ls local/
```

### PM2 crashes / restarts constantly
```bash
pm2 logs ecohealth-backend --lines 50
# Common causes:
#   - Missing .env file
#   - Wrong DB password
#   - Port 3000 already in use
lsof -i :3000
```

### Nginx 502 Bad Gateway
```bash
# Backend is not running or crashed
pm2 status
pm2 restart ecohealth-backend

# Check if backend responds directly
curl http://localhost:3000/health
```

### Port already in use
```bash
# Find what's using a port
lsof -i :3000  # Backend
lsof -i :80    # Nginx
lsof -i :443   # Nginx
lsof -i :9000  # MinIO
lsof -i :5432  # PostgreSQL
lsof -i :6379  # Redis
```

## Architecture Overview

```
                    ┌─────────────┐
                    │   Internet   │
                    └──────┬───────┘
                           │
                    ┌──────▼───────┐
                    │    Nginx     │  ← Port 80/443 (SSL)
                    │  (reverse    │
                    │   proxy)     │
                    └──┬───┬───┬───┘
           ┌───────────┘   │   └──────────┐
           │               │              │
    ┌──────▼──────┐  ┌─────▼─────┐  ┌─────▼─────┐
    │   Frontend  │  │  Backend  │  │  MinIO    │
    │  (static    │  │  (Node.js │  │  (S3 file │
    │   files in  │  │  Express  │  │  storage) │
    │   /dist)    │  │  + Socket │  │  Port 9000│
    │             │  │  Port 3000│  │           │
    └─────────────┘  └─────┬─────┘  └───────────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
       ┌──────▼─────┐ ┌───▼────┐ ┌────▼─────┐
       │ PostgreSQL │ │ Redis  │ │  PM2     │
       │  (Port     │ │ (Port  │ │ (process │
       │   5432)    │ │  6379) │ │  manager)│
       └────────────┘ └────────┘ └──────────┘
```

## Services & Ports

| Service      | Port  | Managed by        |
|-------------|-------|-------------------|
| Nginx        | 80, 443 | systemd          |
| Backend API  | 3000  | PM2               |
| PostgreSQL   | 5432  | systemd           |
| MinIO        | 9000  | systemd           |
| Redis        | 6379  | systemd           |
| WebSocket    | /ws   | Nginx → Backend   |

| What              | Path                              |
|-------------------|-----------------------------------|
| App root          | `/opt/ecohealth`              |

| Backend .env      | `/opt/ecohealth/backend/.env` |
