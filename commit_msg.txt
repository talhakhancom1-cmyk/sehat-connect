Add SMTP diagnostic endpoint + full OTP system

Bug A - SMTP diagnostic:
- New GET /api/email-config/diagnose endpoint that shows:
  - Stored config (host, port, secure, username, from_email)
  - Password decryption status (whether JWT_SECRET matches)
  - Actual SMTP connection test with real error (code, response)
  - Which env keys are set (EMAIL_ENCRYPTION_KEY, etc.)
- Admin panel now has a "Run Diagnostic" button that shows
  all this info inline, auto-runs when a test email fails
- This replaces guessing with actual evidence: the user can
  see exactly what's stored, whether the password decrypts,
  and the specific SMTP error (EAUTH, ETIMEDOUT, etc.)

Bug B - OTP system (was completely missing):
- Created OtpCode model (email, code, purpose, expires_at,
  used, attempts) with table migration in server.js
- POST /api/auth/request-otp: generates 6-digit code, stores
  with 10-min expiry, sends via email. Rate limited (3/10min).
- POST /api/auth/verify-otp: validates code, checks expiry,
  max 5 attempts, marks as used on success.
- Register.jsx now checks if enable_signup_otp is on; if so,
  sends OTP after form validation and shows a 6-digit input
  screen before creating the account.
- Resend timer (60s cooldown), back button, graceful fallback
  if SMTP isn't configured.
