#2 Doctor Schedule - Time-Slot Based Availability:

- Doctors can now define time ranges per day (e.g. 9:00-10:30) that
  auto-generate slots based on the configured duration
- New endpoint: GET /api/schedules/available-slots?doctor_id=X&date=Y
  Returns available slots after removing breaks and booked appointments
- BookingModal now uses the available-slots endpoint as primary source
  (falls back to legacy method if endpoint unavailable)
- Existing manual slot toggling still works alongside time ranges
- Break feature still carves out unavailable time within slot schedule

#3 Do Not Disturb Mode for Doctors:
- Added do_not_disturb boolean to User model
- POST /api/auth/toggle-dnd endpoint to toggle DND on/off
- Backend: call:initiate socket event checks target's DND status —
  if enabled, call is auto-blocked with "doctor unavailable" message
  (calls never ring through)
- Frontend: DND toggle in DoctorDashboard with visual indicator
- Notification sounds muted when DND is on (chat messages still arrive,
  just silently — per user's decision)
- Chat messages and notifications are NOT blocked, only calls + sounds

#4 Virtual Waiting Room - Appointment-Time-Gated Call Access:
- New WaitingRoom component with live countdown
- Patient side: clicking call button checks appointment time:
  - >10 min before: "Too early to join" message
  - 10 min before → appointment time: Waiting room with countdown
  - At/after appointment time: "Join Call" button activates
  - Appointment completed/cancelled: "Appointment ended" message
- Doctor side: no time gate — can call at any time
- Added video call button alongside voice call button in ChatThread
- Waiting room tied to the specific appointment via conversation's
  appointment_id
- Patient can join any time while appointment status is active
  (confirmed/in_progress/pending)
