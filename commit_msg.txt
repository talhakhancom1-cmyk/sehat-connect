Fix SMTP error propagation, age calc, geolocation, camera switch, video quality

Bug A - SMTP test email fails:
- Root cause: getTransporter() captured the real SMTP error from
  transporter.verify() but sendEmail() ignored it and returned a
  generic "Email not configured or SMTP connection failed" message.
- Fix: Propagate the actual error through getTransporter() return
  value. Added detailed error messages for common failure codes
  (EAUTH, ECONNECTION, ETIMEDOUT, ESOCKET, EENVELOPE).
- Added connection/greeting/socket timeouts to avoid hanging.
- Added logging of SMTP config (host, port, secure, username,
  password length) and verify() result for diagnosis.
- Added check for empty/undecryptable password with clear message
  about EMAIL_ENCRYPTION_KEY/JWT_SECRET mismatch.

Bug D.1 - Age shows "17974 years":
- Root cause: DOB "19999-09-09" is a valid JS Date object (year
  19999), so the NaN check passed. The calculation produced a huge
  number.
- Fix: calculateAge() now rejects years < 1900 or > current year.
  Uses proper year/month/day diff instead of epoch math.
- Added backend validation in onboarding.js and auth.js to reject
  DOB with year outside 1900-current year.
- Added migration in server.js to NULL out existing bad DOB values.
